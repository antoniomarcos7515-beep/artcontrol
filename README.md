# ArtControl 🎨

Gerencie clientes e cobranças de projetos criativos. App profissional com tema escuro, funciona **offline** e pode ser instalado como app no celular.

---

## Como publicar no GitHub Pages (passo a passo)

### 1. Criar conta no GitHub
Acesse [github.com](https://github.com) e crie uma conta gratuita se ainda não tiver.

### 2. Criar repositório
- Clique em **"New repository"** (botão verde)
- Nome: `artcontrol`
- Deixe como **Public**
- Clique em **"Create repository"**

### 3. Fazer upload dos arquivos
Na página do repositório vazio:
- Clique em **"uploading an existing file"**
- Arraste **todos** estes arquivos e a pasta `icons/`:
  ```
  index.html
  manifest.json
  sw.js
  icons/
    icon-192x192.png
    icon-512x512.png
    icon-180x180.png
    icon-32x32.png
    apple-touch-icon.png
  ```
- Clique em **"Commit changes"**

### 4. Ativar o GitHub Pages
- Vá em **Settings** (aba superior do repositório)
- No menu lateral, clique em **Pages**
- Em "Source", selecione **Deploy from a branch**
- Branch: **main** → pasta: **/ (root)**
- Clique em **Save**

### 5. Acessar o app
Após ~1 minuto, seu app estará em:
```
https://SEU-USUARIO.github.io/artcontrol/
```

## Instalar no celular como app

### Android (Chrome)
1. Abra o link acima no Chrome
2. Aparecerá um banner **"Adicionar à tela inicial"** — toque nele
3. Ou: toque nos 3 pontinhos → **"Adicionar à tela inicial"**
4. Pronto! O ArtControl aparece com ícone próprio

### iPhone (Safari)
1. Abra o link no **Safari** (obrigatório)
2. Toque no ícone de compartilhar (quadrado com seta)
3. Role para baixo e toque em **"Adicionar à Tela de Início"**
4. Confirme tocando em **"Adicionar"**
